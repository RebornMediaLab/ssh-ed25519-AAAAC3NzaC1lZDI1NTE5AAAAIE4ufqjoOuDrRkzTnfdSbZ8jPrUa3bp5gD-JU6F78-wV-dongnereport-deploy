공동인증서와 간편인증 차이, 어떤 인증서를 발급해야 할까

2026-11-14

정부24, 홈택스, 은행 앱을 쓰다 보면 인증서가 필요하다는 안내를 자주 봐요. 종류가 여러 가지라 헷갈리기 쉬운데, 차이와 고르는 기준을 정리했어요.

크게 세 가지로 나뉘어요

종류 특징 유효기간
공동인증서(옛 공인인증서) 파일 형태로 저장, 가장 폭넓게 지원 보통 1년
금융인증서 클라우드에 저장, 비밀번호로 사용 서비스 안내 확인
민간 간편인증(PASS, 네이버, 카카오, 토스 등) 앱에서 간편하게 발급·사용 서비스마다 다름

유효기간은 서비스마다 달라서 발급 화면의 안내를 꼭 확인하세요. 일부 간편인증은 몇 년 단위로 소개되지만 사업자 안내를 기준으로 해야 해요.

어떤 걸 발급하면 좋을까요

  • 정부24, 홈택스 등 공공 서비스: 지원하는 인증 수단이 서비스마다 달라서, 로그인 화면에 나오는 선택지를 먼저 확인하세요. 오래된 업무 사이트일수록 공동인증서를 요구하는 경우가 있어요.
  • 은행, 카드, 보험: 금융인증서를 많이 써요. 은행 앱에서 발급하면 편합니다.
  • 빠르게 로그인만 필요할 때: 간편인증이 가장 쉬워요. 본인 명의 휴대폰이 필요한 경우가 많으니 확인하세요.

발급할 때 흐름

  1. 발급할 앱(은행 앱, PASS, 네이버 등)을 설치합니다.
  2. 이름, 생년월일, 휴대폰 번호를 입력하고 본인 확인을 해요.
  3. 인증번호와 비밀번호(또는 PIN)를 설정합니다.
  4. 정부24나 홈택스에서 해당 인증 수단을 선택하고 앱에서 승인해요.

공동인증서는 은행 앱이나 은행 누리집에서 발급해서 PC로 옮기는 방식이 흔해요. 발급 방법은 은행과 기관마다 달라서 해당 기관 안내를 따르세요.

주의할 점

  • 만료 전 갱신: 공동인증서는 만료 가까이에는 갱신이 안 되고 새로 발급해야 하는 경우가 있다고 안내돼요. 연말정산이나 신고 기간 전에 만료일을 확인하세요.
  • 본인 명의 휴대폰: 간편인증은 본인 명의 휴대폰이 없으면 발급이 막히기도 해요.
  • 비밀번호 관리: 인증서 비밀번호는 다른 사람에게 알려 주지 마세요. 인증번호를 알려 달라는 전화나 문자는 피싱일 수 있어요.
  • 분실·교체: 휴대폰을 바꿀 때는 새 기기로 인증서를 옮기거나 다시 발급해야 해요. 미리 준비해 두세요.

정리

공공 서비스는 로그인 화면이 지원하는 인증 수단부터 확인하고, 공동인증서와 간편인증을 상황에 맞게 발급하세요. 유효기간과 지원 범위는 서비스마다 다르니 해당 기관의 안내로 확인하세요.

공식 확인처

  • 정부24 (gov.kr), 국세청 홈택스 (hometax.go.kr)
  • 한국인터넷진흥원 KISA 인증 안내 (kisa.or.kr)
  • 거래 은행 고객센터
